# Roadmap for Future Expansions

---
## Expansion 1: Adding Multiplayer Support

### Description
This expansion would involve implementing multiplayer functionality, allowing players to connect and play together in
real-time without needing to be on the same local network and without needing to host a public server.

### Features
- **Online Multiplayer**: Players can connect to a hosted game as players.
- **Chat Functionality**: In-game chat for players to communicate during multiplayer sessions.

#### Player Specific Functions
- **Rotating Player Turns**: Automatically rotate player turns in MP and SP modes.
- **Timer for Questions**: Show a timer after a question is chosen to add urgency and excitement to the game.
- **Text Box for Estimation Questions**: For estimation questions, add a text box where players can input their estimates. 
The host can then mark the correct answer after all players have submitted their estimates.

---
## Expansion 2: Question Repository and Editor

### Description
This expansion would involve creating a question repository and editor, allowing users to create, edit, and manage their 
own question sets.

### Features
- **Question Repository**: A centralized location to store and manage question sets.
- **Question Editor**: A user-friendly interface for creating and editing questions, including support for different 
question types (multiple choice, estimation, etc.).

#### (Extra) UI Overhaul
- **Improved User Interface**: Redesign the UI to be more intuitive and visually appealing, making it easier for users 
to navigate and interact with the application.
